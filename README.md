# 🌐 Portfólio Web - Thiago Marcelino Vieira

Projeto de página de portfólio pessoal desenvolvido como atividade prática do curso técnico em **Desenvolvimento de Sistemas** da escola **SENAI 118 A. Jacob Lafer**.

---

## 📌 Sobre o Projeto

Este projeto consiste em uma estrutura HTML semântica completa para um portfólio pessoal. A aplicação foi elaborada com o objetivo de demonstrar a apresentação de informações pessoais, listagem de projetos com links externos, formulário de contato estruturado e navegação interna por meio de âncoras.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da página (`<header>`, `<main>`, `<section>`, `<fieldset>`, `<table>`, `<footer>`).

---

## 🚀 Estrutura da Página

O documento HTML é organizado nas seguintes seções:

1. **Cabeçalho (`<header>`)**:
   - Apresentação inicial do autor.
   - Menu de navegação rápido (`#sobre`, `#projetos`, `#contato`).

2. **Sobre Mim (`#sobre`)**:
   - Foto de perfil e breve contextualização acadêmica (SESI 265 e SENAI 118).
   - Lista de habilidades (*HTML5, CSS3, JavaScript, PHP*).

3. **Meus Projetos (`#projetos`)**:
   - Tabela exibindo os projetos desenvolvidos, tecnologias aplicadas, status e links para acesso aos sites hospedados no InfinityFree:
     - **Camisa da Vez**
     - **CRUD de Alunos**
     - **Quiz**

4. **Entre em Contato (`#contato`)**:
   - Formulário com campos para captura de nome, e-mail, seleção de assunto e caixa de mensagem.

5. **Rodapé (`<footer>`)**:
   - Informações de direitos autorais e links de contato direto (*E-mail* e *WhatsApp*).

---

## 📂 Como Executar o Projeto

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` diretamente em qualquer navegador moderno (Chrome, Firefox, Edge, Safari).
